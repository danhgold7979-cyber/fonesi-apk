## Error, cancellation and recovery contract

All operations bind operationID, profile serial+generation, package/signer, signed-member digest, expected shared-code generation, current foreground auth and complete affected scope. Recheck immediately before platform dispatch. Cancellation before dispatch has no side effects; after any possible effect retain journal and read back. Missing callbacks, profile disappearance or reboot produce UNCERTAIN/REVIEW until platform state is verified. Never auto-delete personal/work data, reprovision, reinstall to fake update or retry ambiguous mutation. Profile recreation invalidates old authority even if Android recycles numerical IDs.
