## Technical goal

Demonstrate that a **real instance method** defined by a project-owned signed PRIVATE synthetic `PayloadActivity` (constructed through E80) can be explicitly bound to exactly one E79 UUID-scoped Context and read its already verified SharedPreferences/file/SQLite data across two independently restarted host processes, while refusing second binding to another scope. This must remain **method delegation only**: the Activity's framework `getBaseContext()` stays null; no Android ActivityThread, PackageManager registration, guest lifecycle or real third-party execution.
