## Confirmed source gap and conservative scope

E74's opt-in `SyntheticGuestUiProbeActivity` proves a signed PRIVATE `vn.fonesi.payload.PayloadActivity` class name/type/loader but does not test that Android can construct that exact project-owned class. The host Activity presently renders a PRIVATE synthetic View; no third-party or guest ActivityThread lifecycle is implemented. E75 may construct **only** the project-controlled synthetic `PayloadActivity` by its checked public no-argument constructor in a dedicated test host process, without calling onCreate, attaching Application/Context/Window, registering via PackageManager, starting any Android component, using a third-party APK or claiming independent UID/account isolation.
