# Read-only hosted Android environment inventory

Purpose: identify existing capabilities before proposing a separately authorized owned-fixture Android run. Current executor has no known SDK/emulator/KVM; hosted compilation alone does not prove a system image or runtime license.

One first-party Python script reads only the fixed hosted SDK root `/usr/local/lib/android/sdk`, bounded known package subdirectories (platform-tools, emulator, cmdline-tools, platforms, build-tools, system-images), existing license files and `/dev/kvm` stat/access. It does not invoke any discovered executable, SDK manager, adb, emulator, shell, package installer or network client. No sudo/chmod/license acceptance, AVD/device access or secret/environment dumps. No unauthorized Mac access.

Report: versioned fixed JSON with exact GitHub source/run binding, available executable booleans, package metadata file SHA/size and strictly validated selected revision/API/ABI/tag tokens, license filename/hash/size only, KVM character-device and current read/write accessibility booleans. Existing license bytes are neither printed nor interpreted as a new license grant; package/license matching remains unverified. Missing packages/images are honest MISSING observations, not an execution failure or permission to install. Malformed/oversized/symlinked/unreadable entries yield fixed errors, no raw exception/path values. Bound entries, metadata/license bytes and output. Do not read private AVDs or device lists.

Independent synthetic temp-owned tests cover missing SDK, bounded metadata and license hashes without contents, symlink refusal, oversize/malformed fields and KVM mode/access reporting. They do not establish actual hosted capabilities. A dedicated pinned-checkout/upload workflow runs only these affected tests and inventory on ubuntu24.04, exact source checked; no new dependency action. Existing foundation workflow remains unchanged and may conservatively run its current checks for this unknown-path milestone; no new compile claims are manufactured by inventory.

Stop after actual inventory and independent evidence review. Before any runtime, select exact installed image/emulator/license state and review minimum disposable AVD/install/run scope. If missing, ask for the exact official artifacts and legal/runtime actions; no implicit bootstrap or API/storage/signature weakening. This report grants no ANDROID/provider/auth/task acceptance.

Numeric limits: maximum 256 directory scans, 256 entries per directory and 256 package candidates; fixed system-images depth API/tag/ABI only. source.properties <=16KiB, package.xml <=256KiB, each license <=64KiB; final JSON <=256KiB. SDK root and all ancestors/entered directories reject symlinks; files use O_NOFOLLOW plus regular-file fstat/identity/size checks. This is a trusted ephemeral runner observation, not protection against a hostile concurrent privileged filesystem writer. KVM access bits are not proof of emulator usability. Twelve owned synthetic tests passed locally; actual hosted inventory pending.

Traversal is descriptor-anchored from `/`: each directory component opened O_DIRECTORY|O_NOFOLLOW; child file stat/open use retained parent dir_fd, directory enumeration uses scandir(fd). A replaced ancestor cannot redirect a retained descriptor to unrelated data; new symlink traversal is refused. Owned replacement fixture proves this. KVM/executable errors distinguish MISSING/UNREADABLE/UNAVAILABLE from observed false properties; no repeated-observation generator race.

Metadata/license file opens also use O_NONBLOCK so FIFO substitution cannot block before fstat refusal. Child directory ownership transfers before prior-descriptor close; uncertain parent close fails while ensuring acquired child cleanup, without retrying an uncertain old descriptor. Owned fixtures cover both boundaries.
