## Product and non-negotiable boundaries

Native Android, no root, multi-instance manager for Facebook, Messenger, Zalo, TikTok, Threads, X, Shopee and YouTube. Users manually log in; clean instances must not copy sessions. Scan launchable apps subject to package visibility; preserve exact instance identities, names, groups, six fixed styles, direct shortcuts, consented create/open/stop/delete, signed base/split updates, durable queue, access lock, configuration-only backup and redacted diagnostics.

No third-party package/signature modification, identity spoofing, credential bypass, session copying, fake clones via original app/web fallback or bulk social automation. No provider purchases, license acceptance, user-account activity, phone install or store publication implied by engineering permission. New security/legal/device authority requires a separate gate.

Approved direction is Java/native Views + SQLite, superseding the historical proposed Kotlin/Compose + Room recipe, not its behavior/durability requirements. Six accents: teal (default), blue, purple, amber, red, slate. Badge is bounded plain text, never dereferenced; retain exact STYLE-R1-01 rules. Preserve green #126B55 branding reference. Yellow denotes APK chat reporting only, never a theme change. Catalog `(engine_key, clone_id)` is exact opaque metadata, never execution authority and never remapped to UUIDs.

## Evidence and progression

- HOST: independent host contracts on synthetic inputs.
- COMPILE: Android build/lint/package/signature/permission checks.
- ANDROID: actual framework/lifecycle/storage execution.
- PROVIDER: eligible real engine guest execution with provenance, current identity/generation, complete scope and private readback.
- PHONE: physical/OEM/app/account acceptance, owner-controlled accounts.

Higher tiers are not inferred from lower ones. No clone provider/runtime is accepted. An unavailable adapter must truthfully disable guest operations. Isolated host directories/UID claims and Dex loading do not prove hostile-guest isolation or Android framework lifecycle. Unknown identity, scope, readback or partial effects mean stop/quarantine/review, not blind retry. Min API26/target36 is a provisional compile baseline only. First Samsung SM-A525F Android version remains to be recorded; no multi-model support claim until measured.
